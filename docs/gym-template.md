# Gym note template

Keep one note per routine in the Notes app (for example "Push" and "Pull"). Put the newest session at the top. To log a new session, copy the last one to the top, change the date and update the numbers. That way last week's weights are right below what you're doing today.

```
Push

Sat 17 Oct
Flat DB press
50 x 8
50 x 8
50 x 7

Incline DB press
45 x 7
45 x 7
45 x 7

Cable lat raise
12.5 x 14/14
12.5 x 14/14

Pull up
BW x 10
BW x 10

Notes: felt strong, try 55 next time

Tue 14 Oct
Flat DB press
50 x 8
...
```

## Rules

| Line | Meaning |
| --- | --- |
| `Push` (first line) | The workout type for the whole note: Push, Pull, Legs, Upper, Lower, Full body. |
| `Sat 17 Oct` | Starts a session. `17 Oct`, `Oct 17` and `2026-10-17` work too. The year is filled in for you. A type can follow the date (`Sat 17 Oct Legs`). |
| `Flat DB press` | An exercise: any line without numbers. Spelling is forgiving (`DB press flat`, `tricep push down`, `pec flys` all match). |
| `50 x 8` | One set: weight x reps, in lb. Write `20kg x 8` for kilos. |
| `BW x 10` or `10` | A bodyweight set. |
| `12.5 x 14/14` | Left and right reps for single-arm or single-leg work. |
| `Notes: ...` | Free text for that session. |

A note with no date line is saved as today's session.

## Sending it

In the note, tap Share, then **Log workout**. The Shortcut sends the whole note. Every dated session in it is saved, and sending the same note again only updates those sessions, so it never creates duplicates. The reply tells you what was saved and lists any line it couldn't read. Setup: [shortcuts.md](shortcuts.md).
